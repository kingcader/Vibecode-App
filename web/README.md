# Vibecode Landing Page

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/yourusername/Vibecode-App&project-name=vibecode&repository-name=vibecode-app&root-directory=web&env=ANTHROPIC_API_KEY,SUPABASE_URL,SUPABASE_ANON_KEY)

## Quick Deploy

Click the button above to deploy to Vercel in one click!

Or deploy manually:

```bash
vercel --prod
```

## After Deploy

Add these environment variables in Vercel Dashboard:

- `ANTHROPIC_API_KEY` - Get from https://console.anthropic.com
- `SUPABASE_URL` - Get from https://supabase.com
- `SUPABASE_ANON_KEY` - Get from Supabase project settings
- `SUPABASE_SERVICE_KEY` - Get from Supabase project settings

## Environment Variables

Copy `.env.example` to `.env` and fill in your keys:

```bash
cp .env.example .env
```
